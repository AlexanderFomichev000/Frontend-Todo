Todo List
Простой и удобный список задач, созданный в рамках изучения Frontend-разработки.
Проект позволяет добавлять задачи, отмечать их выполнение и управлять своим списком дел через удобный интерфейс.

Функционал
- Добавление новых задач
- Отметка задач как выполненных
- Удаление задач
- Удобное управление списком
- Адаптивный дизайн для разных устройств

Используемые технологиями веб-разработки:
- HTML5 — структура страницы
- CSS3 — стилизация и адаптивность
- JavaScript — логика приложения и взаимодействие с пользователем

Цель проекта:
Целью создания проекта было изучение основ Frontend-разработки:
- работа с HTML-структурой;
- создание пользовательского интерфейса;
- работа с CSS;
- использование JavaScript для добавления интерактивности;
